C Bank Management System
A modular, console-based banking application built in C to demonstrate persistent data storage, memory management, and secure file I/O operations.

Features
Binary Serialization: Securely saves C structures directly to .dat files.

User Authentication: Login system utilizing strcmp for credential verification.

Modular Architecture: Clean separation of headers (.h) and source code (.c).

How to Build and Run
Clone this repository.

Run make in the root directory.

Execute the program using ./bin/bank_app.
